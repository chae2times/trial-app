# 체험단 노트

체험단 신청·발표·후기 일정을 한 화면에서 관리하는 1인용 웹앱입니다.
HTML 파일 하나에 화면·기능·초기 데이터가 모두 들어 있어서, 브라우저만 있으면 어디서든 열립니다.

## 쓰는 법

1. 폰 브라우저에서 아래 주소를 엽니다.
   `https://chae2times.github.io/trial-app/`
2. 브라우저 메뉴에서 **홈 화면에 추가**(또는 **앱 설치**)를 누릅니다.
   - Android Chrome: 오른쪽 위 ⋮ → **홈 화면에 추가**
   - iPhone Safari: 공유 → **홈 화면에 추가**
3. 홈 화면 아이콘을 누르면 주소창 없는 앱 화면으로 열립니다.

## 화면

| 탭 | 내용 |
|---|---|
| 홈 | 오늘 할 일, 발표 대기, 마감 임박 |
| 목록 | 전체 캠페인 검색·필터·정렬 |
| 캘린더 | 발표일·마감일·방문일을 월 단위로 |
| 정산 | 받은 제품·현금성 정산과 입금 체크 |
| 설정 | 플랫폼별 계정, JSON 내보내기/가져오기 |

## 저장 방식

입력한 내용은 **그 브라우저의 localStorage** 에만 저장됩니다. 서버로 보내지 않습니다.
그래서 기기나 브라우저를 바꾸면 내용이 보이지 않으니, 옮기기 전에 **설정 → JSON 내보내기**로 백업한 뒤
새 기기에서 **JSON 가져오기**로 불러오세요.

## 구성

```
index.html          앱 본체 (화면·스크립트·초기 데이터)
manifest.json       홈 화면 추가용 앱 정보
sw.js               오프라인에서도 열리게 하는 서비스워커 (네트워크 우선)
icon-*.png          앱 아이콘 (192·512·maskable·apple-touch)
robots.txt          검색엔진 수집 차단
```

GitHub Pages(`main` 브랜치 루트)로 배포됩니다.
